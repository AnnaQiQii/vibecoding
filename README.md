# vibecoding · 个人主页

一个纯 HTML / CSS / JS 的**动效版**个人主页（横向滚动、粒子随鼠标/点击变形、视频播放），无需任何构建工具。

## 本地预览

直接双击打开 `index.html` 即可。

## 修改内容

- `index.html`：名字、自我介绍、作品、技能、联系方式（搜索「你的名字」替换）
- `style.css`：颜色、字体、布局（顶部 `:root` 里改主题色）
- `script.js`：所有动效（顶部 `NAME` 改粒子显示的名字，`SHAPES` 里可加新形状）
- `assets/showreel.mp4`：示例视频，换成你自己的视频（同名覆盖即可）

## 免费上线（GitHub Pages）

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存后几分钟即可通过
`https://<你的用户名>.github.io/vibecoding/` 访问。
